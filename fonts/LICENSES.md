# Bundled font licenses

Fonts embedded into the `cv` binary (spec §2: open licenses only). License texts ship
alongside each font file in this directory.

| Font | Files | License | Source |
|---|---|---|---|
| Inter | `Inter-{Regular,SemiBold,Bold,Italic,BoldItalic}.ttf` | SIL Open Font License 1.1 (`Inter-LICENSE.txt`) | https://github.com/rsms/inter/releases/tag/v4.1 |
| JetBrains Mono | `JetBrainsMono-{Regular,Bold,Italic}.ttf` | SIL Open Font License 1.1 (`JetBrainsMono-LICENSE.txt`) | https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304 |

M1 bundles the families the starter CV and the `compact` template need. The remaining
spec §2 families (IBM Plex Sans, IBM Plex Mono, Source Sans 3) are added in M3 together
with the `cv fonts` command.
